A FEW MINUTES TO GET STARTED

Set up your radar.

No server. No shared passwords. Just your browser.

01

Load the extension

In Chrome, Edge, or a Chromium browser that supports extensions, open the extensions page. Enable Developer mode, choose Load unpacked, and select the SRC folder. Pin Product Pulse, then click its icon.

02

Use your signed-in page

Sign in to the product site in the same browser profile. Search a keyword, sort by highest price, and copy the first-page URL. Add it as a monitor. If the URL doesn’t retain the keyword or sorting, monitoring that search won’t work reliably.

03

Save the baseline

The first check records every detected product on page one, without new-product alerts. Later checks compare product IDs. Items leaving the first page trigger an update, not a claim that the product was deleted from the site.

04

Keep the browser running

The extension opens a temporary background tab for each check, then closes it. Keep your PC awake, browser running, and account signed in. Checks are queued; browser throttling, network delays, and sleep can delay alerts. It does not bypass verification or access restrictions.
